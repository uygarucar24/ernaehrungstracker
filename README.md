# Ernährungstracker

Erfassung und Auswertung von Ernährungsdaten (z. B. Mahlzeiten, Kalorien, Makronährstoffe).

## Status

    ernaehrungstracker/

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```
